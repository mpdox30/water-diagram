# ข้อมูลดิบสำหรับ engine (ชุดย่อยที่ bundle มากับ repo)

โฟลเดอร์นี้เป็นชุดข้อมูลดิบขั้นต่ำที่ engine ต้องใช้ ก็อปมาจาก
`ARCHIVE_pilot_v1_offline_pipeline/01_data_raw/` (ซึ่งมีข้อมูลครบทั้ง 77 จังหวัด รวม ~1.4GB — ใหญ่เกินไปที่จะ
ใส่ทั้งหมดใน git repo) โดยตอนนี้ bundle มาเฉพาะที่จำเป็นสำหรับตำบล/จังหวัดที่ใช้งานจริงอยู่:

- `admin_boundary/` — ขอบเขตตำบล/จังหวัดทั่วประเทศ (82MB, จำเป็นสำหรับทุกตำบล ไม่ว่าจะเลือกจังหวัดไหน)
- `provincial_gis/38_phitsanulok/` — ข้อมูลทางน้ำดิบของจังหวัดพิษณุโลก (11MB, ครอบคลุมตำบลนครป่าหมาก)

**เมื่อจะเพิ่มตำบลในจังหวัดใหม่**: คัดลอกโฟลเดอร์ `provincial_gis/<n>_<slug>/` ของจังหวัดนั้นจาก
`ARCHIVE_pilot_v1_offline_pipeline/01_data_raw/provincial_gis/` มาใส่ไว้ที่นี่แล้ว commit เพิ่ม (แต่ละจังหวัด
ขนาดประมาณ 10-35MB เท่านั้น ไม่กระทบขนาด repo มาก)
